# Contributing

Keep glyph vectors, font metrics and provenance in sync. Preserve the distinction between historical traces, contemporary inferred designs and composed forms. A visual resemblance alone does not authenticate a source.

Rebuild the TTF and offline desk with the commands in README.md, then run the browser tests. Inspect edited forms in ordinary words and at normal reading sizes, including counters, detached dots and accent placement.

Include a stable item link, source credit and reuse basis for a new historical form. Do not commit downloaded scans, paper figures, credentials or local environment files. Clearly identify AI-assisted designs and retain the artwork's ShareAlike terms.

Code contributions use MIT; font/glyph/artwork contributions use CC BY-SA 2.0. See LICENSE and LICENSE-FONT.

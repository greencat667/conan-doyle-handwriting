# Conan Doyle Letters — v0.8

Install conan-doyle-letters-study.ttf, or open handwriting-desk.html locally. Type a note, select the A variant and font/note treatment, then export SVG or PNG. Transparent export omits the paper background. Text/settings stay in your browser.

All printable ASCII characters are supported, plus a selected accented subset. The desk identifies inferred/composed forms in amber and displays boxes for unsupported characters. Use Character sheet and Word proof to inspect results.

58 of 62 English alphanumerics are traced; X/Z/6/7 are inferred. Six punctuation forms are traced; £/&/double quotes/+/= use contemporary designs. These designs are not historical attestations. Joining strokes are inferred and desk-only; optical kerning is shared with the installable font. OpenType ss01 selects the rounded body A.
